问题：上一版的评分要读者再注册一次本站账号。这个站的读者本来就都有 GitHub 账号，
多一道注册是不必要的门槛。

搜过三条 GitHub 原生路径：
- Discussions 投票：原生支持 1-5，但创建投票只能手点（GraphQL createDiscussion
  至今不支持 poll，社区仍在提需求 #192371），46 个部件就要手建 46 个投票 -> 放弃
- giscus 反应：只能表达 thumbs-up，没有 1-5 分档，也无法聚合进排序 -> 只作辅助
- Issue Forms + Actions：GitHub 身份天然可信、表单结构化、Actions 能自动聚合、
  每条评分可追溯到人和依据、维护者可关闭 -> 采用
