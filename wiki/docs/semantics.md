## 物理红线

| id | name | why |
|---|---|---|
| RL-01 | 扭矩密度 | 受永磁体剩磁、铜损散热与减速器许用扭矩共同限制，控制算法无法突破材料极限 |
| RL-02 | 峰值/额定比 | 峰值受绕组热容与磁路饱和限制，是时间的函数而非常数 |
| RL-03 | 背隙测量条件 | 背隙随加载扭矩变化，空载值可显著优于 ±3% 额定扭矩下的测量值 |
| RL-04 | 重复定位 vs 绝对精度 | 两者通常相差 1–2 个数量级，混用即失去意义 |
| RL-05 | 防护等级作用范围 | 关节薄弱点通常在出线口与输出轴动密封；动密封还会带来附加摩擦扭矩 |
| RL-06 | 编码器位数≠系统精度 | 分辨率是量化步长下界，不含齿隙、柔轮变形、热漂移与安装误差 |

## 单位换算

| from | to | formula |
|---|---|---|
| rpm | rad/s | rad_s = rpm * pi / 30 |
| sec/60deg | rad/s | rad_s = (pi/3) / t_sec |
| kgf·cm | N·m | Nm = kgf_cm * 0.0980665 |
| arcmin | deg | deg = arcmin / 60 |
| g·cm² | kg·m² | kgm2 = gcm2 * 1e-7 |
| bit(单圈) | deg(量化步长) | deg_step = 360 / 2**bits |

## 可比性分级

| grade | name | condition |
|---|---|---|
| A | 可直接比较 | 同一物理量 + 同一负载/温度/电压工况 + 同一测量端（输出端）+ 声明额定或峰值 |
| B | 换算后可比 | 同一物理量，单位不同但换算关系确定，且工况声明一致 |
| C | 仅同厂商内可比 | 有数值但缺工况声明；同厂商内部口径通常自洽 |
| D | 不可比 | 定性描述、缺失、或物理量本身不同；放进对比表就是选型事故的起点 |

## 字段语义

| field | label | meaning |
|---|---|---|
| tau_peak_Nm | 峰值扭矩 | 分子通常是堵转或短时过载值，必须配持续时间与初始温度才有工程意义 |
| tau_rated_Nm | 额定扭矩 | 可连续输出且热稳定的扭矩，需注明母线电压与环境温度 |
| tau_basis | 扭矩口径 | 本行 tau_peak_Nm 对应的是峰值还是额定；两者混比会让排序整体反转 |
| mass_kg | 质量 | 整机（含减速器、编码器、刹车、外壳、线缆）称重值 |
| gear | 减速比 | 给定时 armature 随 N² 放大；不判优劣——高减速比换扭矩但压死速度 |
| speed_noload_rpm | 空载转速 | 输出端空载转速；与减速比由速度律耦合，决定腿尖速度上限 |
| rotor_inertia_kgm2 | 转子惯量 | 电机侧转子惯量。若厂商直接给折算值，见 inertia_basis=output |
| inertia_basis | 惯量口径 | rotor=电机侧；output=厂商已折算到输出侧（等于 N²·J） |
| armature_kgm2 | 关节反射惯量 | MuJoCo 关节的 armature，等于 N²·J。高减速比时常占关节表观惯量 40–80% |
| frictionloss_Nm | 库仑摩擦 | 几乎无厂商公布。留空比填一个估计值诚实 |
| source_tier | 来源等级 | A=官方 datasheet 逐项核对；B=厂商页面或广泛引用，未逐项复核；C=二手来源 |
| price_cny | 参考价 | 挂牌或公开报价，不含运费税费，不是实时价 |

## 向供应商问询清单

1. 额定扭矩：同时索取母线电压、环境温度、连续运行时长、测量端（电机端/输出端）
2. 峰值扭矩：同时索取允许持续时间、起始温度、循环占空比
3. 背隙：同时索取测量加载扭矩、是减速器背隙还是整机回差
4. 精度：区分重复定位精度与绝对定位精度，并注明测量温度
5. 质量：确认是否含减速器、编码器、刹车、外壳、线缆
6. IP 等级：确认是否覆盖出线口与输出轴动密封
7. 写不进技术协议的参数，验收时不具备约束力
