# 优宝特 Y30

![Y30](/parts/yobotics-y30.png)

## 简介

<div class="rb-intro">
<p>官方参数表：站立负载最大 150 kg、行走负载最大 80 kg，payload_kg 取行走值 80；续航空载持续行走 &gt;5 h、有效负载作业 &gt;2.5 h；攀爬台阶高度 30 cm、爬坡角度 40°；防护 IP54；工作温度 -25~50 ℃；重复定位精度 ≤±6 cm。</p>
<p>官网 Y30 参数表未列自由度与对外接口，两项留空；电源适配器输出 29.4V 3A，但未给电池额定电压。</p>
<p>选配 3D 激光雷达与深度相机，价格需询价。</p>
</div>

## 关键参数

| 字段 | 值 |
|---|---|
| 整机质量 (kg) | 60 |
| 负载 (kg) | 80 |
| 最高速度 (m/s) | 4 |
| 尺寸 (mm) | 1100×475×610（站立）；930×450×370（折叠） |
| 越障高度 (mm) | 300 |
| 爬坡角 (°) | 40 |
| 电池 | 25 Ah |
| 续航 (h) | >5 h（空载）/ >2.5 h（负载） |
| 算力平台 | UpBoard ×1：Intel Atom x5-Z8350（2×32 GB） |
| 传感器 | 选配 3D 激光雷达 ×1、深度相机 ×1 |
| 官方文档 | https://www.yobotics.cn/fuwuzhichi/ |
