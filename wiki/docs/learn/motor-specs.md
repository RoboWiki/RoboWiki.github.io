# 关节电机参数怎么读：六个数字背后的坑

选型时最常犯的错不是「算错」，而是**拿错了口径**——把电机端的扭矩当输出端用，把 1/3 堵转扭矩当持续扭矩，把 kg·cm 当 N·m。这篇把六个参数逐个拆开，每个都给一个能回查来源的例子。

## 一、峰值扭矩与额定扭矩

厂商手册通常给两个数：

| 名称 | 含义 | 能不能持续 |
|---|---|---|
| 峰值扭矩 | 短时间内能出的最大扭矩 | 不能。手册必须给出**持续时间**与**初始温度** |
| 额定扭矩 | 长期运行不超温的扭矩 | 能，但前提是散热条件与手册一致 |

**坑一：只写「峰值」不写持续时间。** 有的是 3 秒，有的是 1 秒，有的是「≤1 s，初始 25 ℃」。这三个数完全不是一回事。本站的数据闸门里有一条规则：峰值 / 额定 > 3 时，必须补持续时间与初始温度说明，否则报警——因为比 3 倍的比值本身就说明厂商在用短脉冲刷数字。

**坑二：用额定值算动态性能。** 额定是热约束，不是动力学约束。算加速度要用峰值（并且按你的实际占空比打折），算温升才用额定。

## 二、减速比：输出端还是电机端

这是最容易出错的一项。同一个电机的扭矩，写 0.33 N·m 和写 6.34 N·m 都可能「正确」，区别只在口径。

以 RoboMaster M3508 P19 为例（减速比 359/187 ≈ 19.203）：

```
电机端峰值   0.33 N·m
× 减速比     × 19.203
= 输出端     6.34 N·m
```

本站的口径是**一律输出端（含减速箱）**，因为选型时你关心的是关节出多少力。厂商手册经常只写电机端，那就必须自己乘上去，并在 `notes` 里写清换算过程。

> 减速比是 359/187 这种分数时不要手算成 19.2 就完事。19.203 和 19.2 在 6 N·m 量级上差 0.001 N·m 无所谓，但在惯量折算里是**平方关系**，累计误差会放大。

## 三、转速与功率

转速同样有口径问题：空载转速 vs 额定转速，输出端 vs 电机端。空载转速是理论极限，实际工作点在「空载转速的一半、堵转扭矩的一半」附近效率最高。

功率不要直接乘峰值扭矩 × 空载转速——那个值远超电机的实际输出，因为扭矩和转速不能同时到顶。要按工作点算：

```
P ≈ τ_工作 × ω_工作
```

## 四、Kt（扭矩常数）

`Kt` 把电流换成扭矩：`τ = Kt × I`。它的用处是**判断你的驱动器电流够不够**。

手册给的单位常见两种：`N·m/A` 与 `kg·cm/A`。飞特的手册就是后者，`8.7 kg·cm/A` 要除以 10.197 才是 `0.85 N·m/A`。本站数据里同时保留原始值与换算值（`specs.torque_raw`），就是为了让这个换算可核对。

反过来，如果你知道需要的扭矩，就能反推峰值电流：

```
I_峰值 = τ_峰值 / Kt
```

然后去看驱动器标称电流有没有余量（通常要留 20–30%）。

## 五、转子惯量与折算

转子惯量 `J_rotor` 是电机自己的，折算到输出端要乘减速比的平方：

```
J_输出端 = J_rotor × i²
```

所以大减速比会让「电机侧的小惯量」在输出端变得很大——这既是优点（负载扰动被削弱）也是缺点（反驱阻抗大、力控变难）。准直驱（quasi-direct-drive）就是在这两者之间找平衡，减速比通常 6:1–10:1。

## 六、电压与母线

手册写 `24 V` 通常是额定，实际允许范围会写在电气特性里（例如 `16.8–25.2 V`）。有两点要注意：

1. **母线电压降**：满负载时电池电压会掉，掉到欠压保护点就停机。
2. **高压款能省一级电源**：像飞特 SM160B 支持 16.8–25.2 V，可以直接吃 24 V 母线，不必为它单独降压。

## 附：一个完整的换算实例

| 项 | 手册值（电机端） | 换算后（输出端） |
|---|---|---|
| 峰值扭矩 | 0.33 N·m | 6.34 N·m |
| 额定扭矩 | 0.16 N·m | 3.07 N·m |
| 减速比 | 359/187 | 19.203 |
| 质量 | 0.365 kg | 0.365 kg（不含驱动器） |

这三个数字在[部件库的 M3508 P19 页面](/parts/actuator/dji-m3508-p19)里都有，且标了 `A` 级来源——逐项对过厂商手册。
