# 第一次做整机选型：先算什么，后算什么

顺序错了会白买一轮。最常见的错误是**先挑电机再想需求**——看到别人用某个型号就跟着买，装上去才发现扭矩不够或者太沉。

正确的顺序是倒推：任务 → 自由度 → 关节扭矩 → 电机 → 算力 → 传感器。

## 第 0 步：先把任务写成一句话

不要写「做一个四足机器人」，要写清楚三件事：

1. **负载**：要带多重的东西（含自身）？
2. **地形/工况**：平地、草地、楼梯、碎石？要不要跳？
3. **时长**：一次要连续跑多久？

这三个决定了后面所有数字。写不出来就先别选型——选了也会返工。

## 第 1 步：自由度

自由度不是越多越好，每个自由度都要付三份成本：一个电机、一条线、一份调试时间。

| 形态 | 常见自由度 | 说明 |
|---|---|---|
| 四足 | 12（3×4） | 每条腿 3 个：髋外展、髋俯仰、膝 |
| 轮足 | 12–16 | 在四足上加轮，多出驱动轮 |
| 人形 | 22–53 | 手臂与腰的自由度决定上半身能力 |
| 双足 | 10–12 | 髋 3 + 膝 1 + 踝 2，每腿 |

先问「少一个自由度会怎样」。大多数第一次做的项目，12 自由度四足已经够用。

## 第 2 步：关节扭矩（最关键的一步）

单腿支撑时，髋/膝关节要承受整机重量加动态冲击。用最粗糙但够用的静力估算：

```
τ_关节 ≈ m × g × L / n_支撑腿 + m × a × L / n_支撑腿
```

- `m` 整机质量（kg）
- `L` 关节到足端的水平距离（m），取最大伸展姿态
- `n` 同时着地的腿数（走的时候 2，跑的时候可能 1）
- `a` 期望加速度（m/s²），保守取 5–10

举个实算：整机 16 kg、腿长 0.35 m、双足支撑、加速度 5 m/s²

```
静力项 = 16 × 9.8 × 0.35 / 2 ≈ 27.4 N·m
动态项 = 16 × 5    × 0.35 / 2 ≈ 14.0 N·m
合计   ≈ 41.4 N·m
```

**留 1.5–2 倍余量** → 需要 60–80 N·m 的峰值扭矩。

这个量级对应什么电机？去[部件库按峰值扭矩排序](/catalog)看：

- 达妙 DM-J10422P-2EC：峰值 400 N·m（远超需求，但重量 2.7 kg）
- 达妙 DM-J8009P-2EC 一类：峰值 40–60 N·m 区间
- M3508 输出端 6.34 N·m：**不够**，这就是为什么 RoboMaster 上的四足仍需要减速箱更大的方案

> 估算的意义不是精确，是**排除**。它能让「明显不够」和「明显过量」的型号先出局，剩下的再进详情页比细节。

## 第 3 步：电机 → 驱动器

扭矩定了，反推电流：

```
I_峰值 = τ_峰值 / Kt
```

然后确认驱动器：电流余量 20–30%、支持的总线、支持的编码器类型。很多项目栽在「电机买了，驱动器电流不够」或者「编码器协议不匹配」。

配对细节见[电控链路怎么搭](/learn/control-chain#驱动器与电机怎么配)。

## 第 4 步：算力与传感器怎么定档

先写清楚要跑什么，再选板子：

| 要跑的东西 | 大致需要 | 例子 |
|---|---|---|
| 只做关节闭环 + 简单步态 | MCU | ESP32-S3、NUCLEO-H723 |
| 加 IMU 融合 + 遥控 | MCU（带 FPU） | NUCLEO-F401、Teensy |
| 视觉 SLAM + 建图 | SoC（4–8 GB） | RDK X5、Jetson Orin Nano、树莓派 5 |
| 跑 VLA / 大模型推理 | SoC（16 GB+，带 NPU） | Jetson Orin NX 16GB、AGX Orin |

传感器按「必须先有」排序：

1. **IMU**：姿态是步态的前提，频率要 ≥ 200 Hz，选带温补的模块
2. **关节编码器**：多数一体关节电机自带
3. **深度相机或激光雷达**：要建图/避障才上，别一开始就买最贵的
4. **力矩/足端触觉**：上台阶、盲走时才需要

## 第 5 步：回到数据，压到 3 个候选

前三步会给你一张约束表：扭矩 ≥ X、质量 ≤ Y、电压 = Z、接口 = CAN。带着它去[部件库](/catalog)按列排序，把候选压到 3 个，然后：

- 看**来源等级**：`A` 级是逐项对过厂商手册的，`B` 级是商品页转述
- 看**缺失字段**：写成 `—` 的是真没公布，不是我们没查
- 看**评分**：有真实使用者打分的优先（样本量 < 3 时只能当参考）

## 常见的错误顺序

| 错误做法 | 后果 |
|---|---|
| 先买电机，再想结构 | 扭矩或重量对不上，返工 |
| 按「别人用什么」照抄 | 别人的负载、腿长、步态都和你不一一样 |
| 一次买齐所有传感器 | 大部分用不上，钱压在仓库里 |
| 忽略线束与端子 | 现场最常见的故障源 |
| 只在官网参数表上比 | 口径不统一，比出来的是假的 |
