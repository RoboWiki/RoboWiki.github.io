# 分享与转载：三条底线

本仓库按 **GPL-3.0** 发布（全文见仓库根目录 `LICENSE`）。转载不用逐篇问，但有三条底线（署名到人、不改数据、分发时附上许可证与源码）。

## 一、署名到人

转载时写清三件事：

1. **来源**：RoboWiki（`https://robowiki.org.cn/`）
2. **作者**：文章页署名的人或「RoboWiki 编辑部」
3. **原文链接**：链到具体那篇文章，不是首页

反例：「来源网络，侵删」。这句话等于没署名，我们不接受。

## 二、不改数据

可以做的：

- 改排版、配图、加自己的批注与补充
- 翻译成其它语言（保留原文链接）
- 摘录片段用于教学材料

不可以做的：

- **改参数、价格、来源等级**（A/B/C 是核对程度的标记，改了就失真）
- 删掉「缺失」的标注（写成 `—` 的字段是真没公布，抹掉会让人以为有数据）
- 把文章结论说成「RoboWiki 官方推荐」（我们没有推荐位，也不收佣金）

## 三、商用可以，但别改数据、别去掉许可

GPL-3.0 允许商业使用，**不需要来问我们**（我们自己的定位是非商业，但许可不限制你）：你可以拿去做课程、做内部选型库、
甚至做成产品的一部分。只有两件事必须做到：

1. **署我们的名**，并保留该条目的 `source_tier`（A/B/C）与 `last_checked` ——
   这两个字段决定了数字的含义，删掉就不是同一份数据了
2. **分发时附上 GPL-3.0 全文与对应源码**（修改后再分发同理）

不允许的是：把数值改掉、结论改掉，然后仍然署名 RoboWiki。

> 厂商手册、商品图、第三方仓库代码不在此列 —— 版权归原方，只能按原方许可使用。
> 其中产品图是我们随条目托管在`RoboWiki` 仓 `assets/parts/` 的（不是外链），出处逐条记在 `image_source`；
> 权利人要求撤下时我们说撤就撤，规则与联系方式见「免责声明与许可」页。

## 四、反过来：我们怎么用别人的内容

对称的规则，写在这里以示公平：

| 来源类型 | 我们的做法 |
|---|---|
| 厂商手册与官网 | 引用数据并标注来源等级；手册只给链接，不镜像文件 |
| 厂商 / 商城产品图 | **下载后随条目托管在`RoboWiki` 仓**（`assets/parts/`），出处记在该条目的 `image_source`；未逐张取得书面许可，权利人要求撤下就撤下（先下架、后讨论） |
| 开源项目（URDF/SDK/配置） | 只链接，不镜像；必须能追到官方仓库 |
| 社区文章与帖子 | 只提炼结论并附链接，不整段搬运 |
| 他人的测评与反馈 | 转述并去标识，不冒用署名 |

如果发现本站有越界使用，请通过投稿页指出，我们会在 48 小时内改。

## 五、引用格式

学术或报告里引用本站，用这个格式：

```
RoboWiki 编辑部. 《从零开始学：第一次做机器人，先做这五件事》[EB/OL].
https://robowiki.org.cn/learn/, 2026-10-30.
```

数据类引用（参数表）建议同时写明**核对日期**，因为价格与固件版本会变。
