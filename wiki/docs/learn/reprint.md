# 分享与转载：三条底线

本站文章默认采用 **署名 — 非商用 — 相同方式共享**。也就是说：**不用逐篇问，但有三条底线。**

## 一、署名到人

转载时写清三件事：

1. **来源**：RoboWiki（`https://robowiki.github.io/`）
2. **作者**：文章页署名的人或「RoboWiki 编辑部」
3. **原文链接**：链到具体那篇文章，不是首页

反例：「来源网络，侵删」。这句话等于没署名，我们不接受。

## 二、不改数据

可以做的：

- 改排版、配图、加自己的批注与补充
- 翻译成其它语言（保留原文链接）
- 摘录片段用于教学材料

不可以做的：

- **改参数、价格、来源等级**（A/B/C 是核对程度的标记，改了就失真）
- 删掉「缺失」的标注（写成 `—` 的字段是真没公布，抹掉会让人以为有数据）
- 把文章结论说成「RoboWiki 官方推荐」（我们没有推荐位，也不收佣金）

## 三、商用先问

以下场景请先联系编辑部（[投稿页](/submit) 里的联系方式）：

- 付费课程、训练营教材
- 产品手册、招投标材料
- 印在商品或包装上
- 任何形式的「付费墙后面」

我们一般都会同意，但要知情——尤其是不希望文章被用来暗示背书某个厂商。

## 四、反过来：我们怎么用别人的内容

对称的规则，写在这里以示公平：

| 来源类型 | 我们的做法 |
|---|---|
| 厂商手册与官网 | 引用数据并标注来源等级，图不搬运（除非明确许可） |
| 开源项目（URDF/SDK/配置） | 只链接，不镜像；必须能追到官方仓库 |
| 社区文章与帖子 | 只提炼结论并附链接，不整段搬运 |
| 他人的测评与反馈 | 转述并去标识，不冒用署名 |

如果发现本站有越界使用，请通过投稿页指出，我们会在 48 小时内改。

## 五、引用格式

学术或报告里引用本站，用这个格式：

```
RoboWiki 编辑部. 《怎么用这个网站》[EB/OL].
https://robowiki.github.io/learn/, 2026-10-30.
```

数据类引用（参数表）建议同时写明**核对日期**，因为价格与固件版本会变。
