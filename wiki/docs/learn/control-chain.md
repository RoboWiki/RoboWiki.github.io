# 电控链路怎么搭：总线、驱动器与频率预算

电机选好之后，真正让人卡住的是链路：**总线带得动吗、驱动器配得上吗、控制周期够用吗**。这篇把三者放在一张表里算。

## 一、总线怎么选

| 总线 | 速率 | 典型用途 | 代价 |
|---|---|---|---|
| CAN 2.0B | 1 Mbps | 关节电机、驱动器（最常见） | 带宽紧张，节点多就撑不住 |
| CAN-FD | 最高 5–8 Mbps（数据段） | 高频率多关节、需要大帧 | 收发器与主控都要支持 |
| EtherCAT | 100 Mbps | 工业多轴、需要硬实时同步 | 主站要专用网卡/协议栈 |
| RS-485 | 常见 1–12 Mbps | 舵机、低成本模块 | 半双工，多主不友好 |
| UART | 通常 ≤ 1 Mbps | IMU、编码器、调试口 | 点对点，抗干扰弱 |

对 DIY 与科研四足/人形，**CAN 是默认答案**。但要算清楚它够不够。

## 二、频率预算：CAN 到底能挂多少关节

一帧标准 CAN（11 位 ID + 8 字节数据）在物理层大约占 108–135 bit（含位填充与帧间隔，取 130 bit 保守估算）。

```
1 Mbps / 130 bit ≈ 7,600 帧/秒
```

一个关节每周期要两帧：**指令下行 + 反馈上行**。所以：

```
每周期帧数 = 关节数 × 2
最大控制频率 = 7,600 / (关节数 × 2)
```

算几个常见配置（单总线、总线负载用满 70% 更现实）：

| 关节数 | 理论最大频率 | 70% 负载下 |
|---|---|---|
| 6 | 633 Hz | 443 Hz |
| 12 | 316 Hz | 221 Hz |
| 16 | 237 Hz | 166 Hz |
| 24 | 158 Hz | 111 Hz |

**结论**：12 个关节跑 1 kHz 闭环，单条 1 Mbps CAN **不够**。现实的三种解法：

1. **分总线**：两条 CAN，各挂 6 个关节 → 每条约 440 Hz（70% 负载）
2. **升 CAN-FD**：数据段 5 Mbps，带宽涨 5 倍，12 关节 1 kHz 有余量
3. **降频 + 插值**：外层 500 Hz 下发，驱动器内部 2–4 kHz 电流环自己跑（多数一体电机就是这么做的）

第三种最便宜，也最常见——**控制频率不等于电流环频率**，别把两者混为一谈。

## 三、驱动器与电机怎么配

四个必须对上的项：

| 项 | 对不上会怎样 |
|---|---|
| **极对数** | 换向错误，电机抖动或直接堵转 |
| **编码器类型/分辨率** | 读不到角度，或角度跳变 |
| **标称电流** | 扭矩上不去，或驱动器过热保护 |
| **电压范围** | 高压电机配低压驱动器 = 出不了额定扭矩 |

电流余量按峰值算完再乘 1.2–1.3。举例：峰值扭矩 60 N·m 的一体关节，`Kt ≈ 0.5 N·m/A`，峰值电流约 120 A——这个量级的驱动器不是随便挑的。

> 一体关节电机（达妙 DM 系列、灵足 RobStride、宇树 GO-M8010）把这些都封在里面，省掉配对问题；代价是驱动器不可换、坏一个换整只。

## 四、时间同步

多传感器融合时，**时间戳比精度更重要**。三条经验：

1. IMU 与视觉的时间戳要能互换：统一到一个时钟源（PTP / 主控 monotonic）
2. 相机硬件触发优先于软件打点，差 10 ms 在 1 m/s 下就是 1 cm 的位移
3. CAN 反馈帧本身不带时间戳，主控收到时刻就是它的时间——总线负载越高，这个误差越大（这就是为什么要留 30% 带宽余量）

## 五、一张检查表

搭之前逐条打勾：

- [ ] 关节数 × 2 帧/周期，算过带宽，负载 < 70%
- [ ] 电流余量 ≥ 20%
- [ ] 极对数与编码器协议与驱动器匹配
- [ ] 母线电压在电机与驱动器**共同**的允许范围内
- [ ] 每条总线两端各有 120 Ω 终端电阻（中间节点不要加）
- [ ] 线束长度与线径按电流算过（大电流用硅胶线，别用杜邦）
- [ ] 有一个独立的总线抓包手段（CAN 分析仪 / 备用口）
- [ ] 急停能切断动力电源，而不是只发软件停止

## 六、线束与端子：最容易被忽略的一环

现场故障里，机械与算法各占一部分，剩下的大多在线束：

- **端子压接**比焊接可靠，压接后用拉力测试
- 大电流回路（电机相线）与信号线（编码器、CAN）**分开走线**，交叉处成 90°
- 拖链内走线要留弯曲余量，反复弯折会断在端子根部
- 有现成端子线的优先买现成的（比如飞特 5264 端子线、达妙电机连接线）——自己做一条的时间成本通常高于买
