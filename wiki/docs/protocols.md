# 总线与协议口径

同一个「电流」在四个驱动里是四个不同的量。不写清编码满量程，跨厂商比电流/力矩就是错的。

| 驱动 | 厂商 | 适用电机 | 电流编码 | 满量程 A | 减速比（协议 / 名义） | 控制模式 |
|---|---|---|---|---|---|---|
| **C620** | DJI RoboMaster | M3508 P19 | int16 线性，满量程 ±16384 ↔ ±20 A | 20.0 | 19.2032 / 19:1 | 电流(力矩) / 转速 |
| **C610** | DJI RoboMaster | M2006 P36 | int16 线性，满量程 ±10000 ↔ ±10 A | 10.0 | 36.0000 / 36:1 | 电流(力矩) / 转速 |
| **GM6020 内置** | DJI RoboMaster | GM6020 | int16 线性，满量程 ±16384 ↔ ±3 A | 3.0 | 1.0000 / 直驱 | 电压 / 电流(力矩) / 转速 / 角度 |
| **内置（MIT 模式）** | 达妙 DM | DM-J4310、DM-J4340、DM-J8009、DM-J10010 | 12 bit 定标：扭矩 ±10 N·m、速度 ±25 rad/s、角度 ±12.5 rad，各自映射到 12 bit | 10.261194 | — / 随型号 | MIT(位置+速度+Kp+Kd+力矩) / 位置速度 / 速度 |
| **一拖四固件** | 达妙 DM | DM-J4310-2EC 一拖四 | int16 线性，满量程 ±16384 ↔ ±10.261194 A | 10.261194 | — / 随型号 | 角度 / 速度 |

### C620（DJI RoboMaster）

- 电流编码：int16 线性，满量程 ±16384 ↔ ±20 A
- 满量程：20.0 A
- 总线：CAN 2.0B, 1 Mbps，控制频率 1000 Hz
- 减速比：协议 `19.20320855614973` / 名义 19:1

::: tip 口径提醒
减速比在协议里按 3591/187 = 19.2032 换算，而手册写「19:1」。做转速↔转子换算时用 19.2032，用 19.0 会有 1.06% 系统性偏差。

证据：`dvc_motor_dji.h: Class_Motor_DJI_C620::Init 默认 __Gearbox_Rate = 3591.0f/187.0f；Current_To_Out = 16384.0f/20.0f`
:::

### C610（DJI RoboMaster）

- 电流编码：int16 线性，满量程 ±10000 ↔ ±10 A
- 满量程：10.0 A
- 总线：CAN 2.0B, 1 Mbps，控制频率 1000 Hz
- 减速比：协议 `36.0` / 名义 36:1

::: tip 口径提醒
C610 与 C620 的电流编码满量程不同（10000 vs 16384）。把 C610 的原始值按 C620 的比例换算会偏大 64%。

证据：`dvc_motor_dji.h: Class_Motor_DJI_C610::Init 默认 __Gearbox_Rate = 36.0f；Current_To_Out = 10000.0f/10.0f`
:::

### GM6020 内置（DJI RoboMaster）

- 电流编码：int16 线性，满量程 ±16384 ↔ ±3 A
- 满量程：3.0 A
- 总线：CAN 2.0B, 1 Mbps，控制频率 1000 Hz
- 减速比：协议 `1.0` / 名义 直驱

::: tip 口径提醒
直驱无减速器，编码器 13 bit 绝对值。手册额定电流 1.62 A，只占满量程 3 A 的 54%——按满量程设计线束会过度。

证据：`dvc_motor_dji.h: Class_Motor_DJI_GM6020 Current_To_Out = 16384.0f/3.0f；Theoretical_Output_Voltage_Max = 24.0f`
:::

### 内置（MIT 模式）（达妙 DM）

- 电流编码：12 bit 定标：扭矩 ±10 N·m、速度 ±25 rad/s、角度 ±12.5 rad，各自映射到 12 bit
- 满量程：10.261194 A
- 总线：CAN 2.0B, 1 Mbps，控制频率 1000 Hz
- 减速比：协议 `None` / 名义 随型号

::: tip 口径提醒
MIT 模式的物理量程是写死在帧格式里的：角度 ±12.5 rad、速度 ±25 rad/s、扭矩 ±10 N·m。电流满量程 10.261194 A 是驱动侧定标值，不是厂商给电机的额定电流——别把它当额定。

证据：`dvc_motor_dm.h: Class_Motor_DM_Normal::Init 默认 __Angle_Max=12.5f, __Omega_Max=25.0f, __Torque_Max=10.0f, __Current_Max=10.261194f；一拖四 Current_To_Out = 16384.0f/10.261194f`
:::

### 一拖四固件（达妙 DM）

- 电流编码：int16 线性，满量程 ±16384 ↔ ±10.261194 A
- 满量程：10.261194 A
- 总线：CAN 2.0B, 一帧驱动 4 个电机，控制频率 1000 Hz
- 减速比：协议 `None` / 名义 随型号

::: tip 口径提醒
教程使用的固件版本为 5051_01。2024-11-19 起达妙更新了一批一拖四固件；**3519 的一拖四版本改用与大疆 C620-3508 相同的协议**，其余型号仍按本文口径。混用两种固件会让同一份代码在 3519 上完全不响应。

证据：`20250120 关于新固件的补充告知.md；dvc_motor_dm.h Class_Motor_DM_1_To_4`
:::

## 自检清单

1. 电机端还是输出端？——减速比换算写清用的是名义值还是协议值（M3508：19 vs 19.2032）
2. 电流满量程多少？——C610 的 10000 与 C620 的 16384 不是一套比例
3. MIT 模式的 ±10 N·m 是帧格式定标，不是电机能力上限
4. 固件版本会改协议——达妙 3519 与大疆 C620 兼容，其余不兼容
5. 控制频率写清：1 kHz 是这些驱动的共同上限，再高要看总线负载
