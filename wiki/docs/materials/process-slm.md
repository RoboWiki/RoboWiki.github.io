# 3D 打印 SLM

<div class="mt-meta">
  <span>加工工艺</span>
  <span>增材制造</span>
  <span>Selective laser melting (SLM)</span>
  <span>来源 B 级</span>
</div>

<div class="mt-intro">
<p>金属粉末床激光熔化。</p>
<p>适合钛合金和铝合金的复杂轻量化件、点阵结构与随形流道；单价高，通常只在小批量或传统加工做不出来的形状上使用。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | 0.1 |
| 公差说明 | 常见 ±0.1 mm，视尺寸与摆放方向；配合面通常要 CNC 后加工 |
| 表面粗糙度 Ra (µm) | 8 |
| 层高 (mm) | 0.03 |
| 最小壁厚 (mm) | 0.4 |
| 最大尺寸 | 常见 250×250×300 mm；工业机可达 380 mm 级 |
| 成本档 | 高 |
| 参考交期 | 5–10 天 |

## 适用材料

<div class="mt-chips"><a class="mt-chip" href="./ti-tc4.html">TC4 钛合金</a><a class="mt-chip" href="./alu-alsi10mg.html">AlSi10Mg 铝合金（SLM）</a></div>

## 可做形态

| 形态 | 规格 | 说明 |
|---|---|---|
| 粉末 | TC4 / AlSi10Mg 等 | 需专用机台与粉末管理；未熔粉末可回收 |
| 定制件 | 逐层激光熔化 | 复杂内腔、点阵、轻量化金属件 |

## 典型应用

<div class="mt-chips"><span class="mt-chip">钛合金轻量化接头</span><span class="mt-chip">点阵/拓扑优化结构</span><span class="mt-chip">小批量金属功能件</span><span class="mt-chip">随形冷却流道</span><span class="mt-chip">定制夹具</span></div>

## 优缺点

**优点**：复杂几何自由度高、可做点阵和内部流道、材料利用率高；钛合金/铝合金都能成型。

**限制**：设备和粉末成本高、单件贵；表面粗糙、需支撑和后处理；残余应力与各向异性要评估。
