<div class="mt-meta">

<div class="mt-intro">
<p>熔融沉积打印。</p>
<p>适合原型、夹具和外壳；层间强度明显低于层内，承力件要按打印方向评估。</p>
<p>PEEK 等高温材料需要高温腔体机型。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | ±0.3 |
| 公差说明 | 常见 ±0.2–0.5 mm，视机台、材料与摆放方向 |
| 表面粗糙度 Ra (µm) | 15 |
| 层高 (mm) | 0.2 |
| 最小壁厚 (mm) | 0.8 |
| 最大尺寸 | 常见 300×300×300 mm，工业机更大 |
| 成本档 | 低 |
| 参考交期 | 1–3 天 |

## 优缺点

**优点**：便宜快、材料广、设备普及；可打印连续纤维/高温材料（高端机）。

**限制**：各向异性明显、层间强度低、表面有纹路、精度低；长丝需干燥。
