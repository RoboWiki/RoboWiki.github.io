<div class="mt-intro">
<p>批量塑料件的首选。</p>
<p>开模后单件成本低、一致性好；小批量或频繁改结构时不划算。</p>
<p>PEEK、PPS、PA 和液态硅胶都能注塑，但工艺窗口差别很大。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | ±0.1 |
| 公差说明 | 常见 ±0.05–0.2 mm，视材料收缩率与模具精度 |
| 表面粗糙度 Ra (µm) | 1.6 |
| 最小壁厚 (mm) | 1 |
| 最大尺寸 | 视模具，常见 < 500 mm |
| 成本档 | 视批量 |
| 参考交期 | 开模 2–6 周；量产 1–3 周 |

## 优缺点

**优点**：批量单价低、一致性好、表面好、可做复杂结构；材料选择多。

**限制**：开模费高、设计变更贵；壁厚/拔模/浇口限制；小批量不划算。
