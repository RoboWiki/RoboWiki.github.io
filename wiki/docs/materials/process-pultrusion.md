# 拉挤成型

<div class="mt-meta">
  <span>加工工艺</span>
  <span>复合材料成型</span>
  <span>Pultrusion</span>
  <span>来源 B 级</span>
</div>

<div class="mt-intro">
<p>连续拉挤成型，适合碳纤维圆管、方管、棒和等截面型材。</p>
<p>轴向性能强、成本低于铺层工艺；只能做等截面，连接处通常要加金属接头或胶接。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | 0.3 |
| 公差说明 | 常见 ±0.2–0.5 mm，视截面与模具 |
| 表面粗糙度 Ra (µm) | 3.2 |
| 最小壁厚 (mm) | 0.8 |
| 最大尺寸 | 等截面连续生产，长度按卷/根 |
| 成本档 | 中 |
| 参考交期 | 2–4 周（含开模/排产） |

## 可做形态

| 形态 | 规格 | 说明 |
|---|---|---|
| 管材 | 圆管/方管 | 连续拉挤，长度可定制 |
| 棒材 | 圆棒/异形棒 | 高轴向强度 |
| 型材 | 等截面异型 | 需开拉挤模 |

## 典型应用

<div class="mt-chips"><span class="mt-chip">碳杆</span><span class="mt-chip">碳方管</span><span class="mt-chip">机器人连杆</span><span class="mt-chip">框架型材</span><span class="mt-chip">无人机管件</span></div>

## 优缺点

**优点**：连续生产、纤维体积分数高、轴向强度/刚度高；成本低于铺层/热压罐。

**限制**：只能做等截面；横向强度和层间强度低；表面富树脂；弯曲/扭转性能一般。
