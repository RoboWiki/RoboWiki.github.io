# 压铸（高压）

<div class="mt-meta">
  <span>加工工艺</span>
  <span>压铸</span>
  <span>High-pressure die casting (HPDC)</span>
  <span>来源 B 级</span>
</div>

<div class="mt-intro">
<p>批量铝合金/镁合金件的首选成型方式。</p>
<p>开模后单件成本低、一致性好；模具费高，结构变更贵，小批量应先用 CNC 或 3D 打印验证。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | 0.1 |
| 公差说明 | 常见 ±0.1 mm，视尺寸与模具；配合面通常还要 CNC 精加工 |
| 表面粗糙度 Ra (µm) | 3.2 |
| 最小壁厚 (mm) | 1 |
| 最大尺寸 | 常见 ≤600 mm，视锁模力与模具 |
| 成本档 | 低-中（批量） |
| 参考交期 | 开模 12–20 天；量产 2–4 周 |

## 优缺点

**优点**：批量单价低、尺寸一致、表面好、可做薄壁复杂形状；铝合金/镁合金都能压。

**限制**：开模费高、小批量不划算；气孔与缩孔风险；壁厚/拔模/浇口限制；后加工和表面处理另算。
