# 3D 打印 SLS

<div class="mt-meta">
  <span>加工工艺</span>
  <span>增材制造</span>
  <span>Selective laser sintering (SLS)</span>
  <span>来源 B 级</span>
</div>

<div class="mt-intro">
<p>粉末床激光烧结。</p>
<p>适合 PA12/PA11 类尼龙，做复杂支架、外壳和小批量功能件；精度和表面不如 CNC，装配面通常还要二次加工。</p>
<p>PEEK 等高温粉末需专用高温机台，不在本表材料清单内。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | 0.3 |
| 公差说明 | 常见 ±0.3 mm 或 ±0.3%，视尺寸与摆放方向 |
| 表面粗糙度 Ra (µm) | 10 |
| 层高 (mm) | 0.1 |
| 最小壁厚 (mm) | 0.8 |
| 最大尺寸 | 常见 300×300×300 mm，工业机更大 |
| 成本档 | 中 |
| 参考交期 | 3–7 天 |

## 适用材料

<div class="mt-chips"><a class="mt-chip" href="./pa12.html">PA12 尼龙</a></div>

## 可做形态

| 形态 | 规格 | 说明 |
|---|---|---|
| 粉末 | PA12/PA11 为主 | 未烧结粉末可部分回收 |
| 定制件 | 无支撑成型 | 复杂内腔、点阵、小批量 |

## 典型应用

<div class="mt-chips"><span class="mt-chip">复杂支架</span><span class="mt-chip">外壳/罩壳</span><span class="mt-chip">夹具/工装</span><span class="mt-chip">点阵/轻量化结构</span><span class="mt-chip">小批量功能件</span></div>

## 优缺点

**优点**：无需支撑、复杂几何自由度高、小批量经济、各向异性小于 FDM。

**限制**：表面粗糙、尺寸精度低于 CNC、材料选择有限；粉末回收比例影响性能。
