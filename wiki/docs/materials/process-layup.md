# 铺层/缠绕成型

<div class="mt-meta">
  <span>加工工艺</span>
  <span>复合材料成型</span>
  <span>Hand layup / filament winding</span>
  <span>来源 B 级</span>
</div>

<div class="mt-intro">
<p>铺层和缠绕是复材的通用成型方式。</p>
<p>适合大尺寸、异形或受力方向明确的碳纤维/玻纤件；一致性依赖工艺控制，承力件要做铺层设计和验证。</p>
</div>

## 工艺能力

| 字段 | 值 |
|---|---|
| 可达公差 (mm) | ±0.5 |
| 公差说明 | 常见 ±0.5 mm，视模具与后加工；配合面通常要 CNC 修整 |
| 表面粗糙度 Ra (µm) | 3.2 |
| 最小壁厚 (mm) | 0.8 |
| 最大尺寸 | 长度可达数米；受芯模/缠绕机行程限制 |
| 成本档 | 中高 |
| 参考交期 | 7–20 天（含模具/固化） |

## 可做形态

| 形态 | 规格 | 说明 |
|---|---|---|
| 板材 | 预浸料/织物层压 | 铺层方向决定强度与刚度 |
| 管材 | 缠绕成型 | 圆管/锥管，纤维沿主应力方向铺放 |
| 型材 | 模压/层压 | 异形件需模具 |
| 定制件 | 手糊/真空袋压 | 小批量、大尺寸异形壳体 |

## 典型应用

<div class="mt-chips"><span class="mt-chip">机械臂连杆</span><span class="mt-chip">无人机机架</span><span class="mt-chip">管件/压力容器</span><span class="mt-chip">异形壳体</span><span class="mt-chip">小批量复材件</span></div>

## 优缺点

**优点**：铺层方向可按受力设计、纤维体积分数高、适合大尺寸和异形件；模具成本低于热压罐。

**限制**：人工依赖大、批次一致性不如拉挤/注塑；层间强度低、易分层；固化周期长，后加工粉尘需防护。
